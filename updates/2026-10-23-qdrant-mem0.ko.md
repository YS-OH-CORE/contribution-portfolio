## 사례 10: Qdrant, 개발 브랜치에서 정식 배포판으로

우리 이슈 #1510에 연결된 외부 수정 #1515가 **2026-10-22 20:35 KST에 공개된 v1.20.0**에 포함됐습니다. 관리자 joein은 **10월 23일 17:33 KST**에 이슈에서 해결을 확인했습니다. 구현·통합 공로는 adityaanikam과 joein에게 있습니다.

SHA256를 확인한 공식 두 배포판을 같은 의존성 환경에서 비교했습니다. 동기·비동기 API 각각의 정상 삭제·삭제 전 오류·실제 커밋 후 오류를 합친 여섯 시나리오에서, **1.19.1은 2개 통과·4개 실패, 1.20.0은 6개 모두 통과**했습니다. 실패 뒤 같은 필터로 재시도하면 목표 기록이 없어지고, 관련 없는 기록은 남으며, 다시 열어도 결과가 유지됐습니다.

이 결과는 삭제 재시도 계약의 좁은 확인입니다. 커밋 후 합성 오류 직후의 메모리·디스크 완전 일치, 전체 트랜잭션 원자성, 전원 장애 내구성, 동시 실행, 원격 서버나 전체 검사 성공으로 확대하지 않습니다. 새 Qdrant 사례를 더하지 않고 기존 **10번**을 갱신합니다.
