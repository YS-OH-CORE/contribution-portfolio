## Roles and evidence

Youngseok supplies questions, direction and corrections. Zero is the AI collaborator performing substantial technical analysis, implementation, execution and writing. Original feature work, integration and reported reruns remain attributed to the external authors. Some external work is also AI-assisted; public account responses are not automatically independent human verification.

Numbers quoted from author responses are **their recorded reruns**, not new tests performed while publishing this portfolio. Narrow branch adoption, local use, design feedback, published credit and upstream merge are distinct outcomes. Important corrections and unresolved limits stay with each case.

## How this collection grows

Work and test first, preserve candidates privately, then publish a concise case once public evidence supports its actual value and contribution. Pending proposals are not promoted as accepted changes. This public repository has a fresh history containing selected portfolio materials, not a mirror of the private working archive.
